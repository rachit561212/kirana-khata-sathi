# Kirana Khata Sathi

Design the frontend of a website that whose name is kirana khata that will make the user uplaod payment reciepts and will extract information from its a shop ledger appKey Highlights & Features:

Interactive 3D Shopfront Animation (<threejs-scene>):

Features a rendered grocery shop with an opening roll-up security shutter gate, warm lit produce shelves, counters, and grocery crates.

Includes stylized 3D character figures—a smiling grocer in an apron and customers outside with shopping bags, animated with subtle idle breathing and interaction.

Includes floating glowing ledger coins and receipt nodes that react to mouse parallax movement.

Hero HUD & Money In/Out Metrics:

Clear value proposition highlighting automated extraction of both Money Spent (supplier wholesale invoices, mandi receipts, distributor bills) and Money Received (daily customer UPI settlements and cash totals).

Instant call-to-actions: "Drop Your First PDF Bill" and "Watch 3D Shutter Demo".

Live Interactive PDF Extraction Sandbox:

Side-by-side demo displaying an authentic distributor PDF invoice on the left alongside real-time extracted structured data on the right.

Line-item breakdown displaying item particulars, quantities, unit costs, GST rates, confidence levels, and automated margin-hike alerts.

Toggle tabs to switch between Money Spent (Vendor Payments) and Money Received (Settlements).

Street-Commerce Feature Suite:

Multi-format ingestion (WhatsApp PDFs, scanned thermal paper, handwritten vouchers).

Vendor credit (Udhaar Khata) reconciliation with automated WhatsApp payment alerts.

Nightly daybook reconciliation before closing down the shop shutter.

Vernacular language support across 7 Indian languages.
